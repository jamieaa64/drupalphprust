# Future work

Do not silently promote these into acceptance requirements for today's extraction.

1. Full One Line Installer matrix: fresh git/local-source installs, update/rerun,
   interrupted builds, offline/failed downloads, name collisions, different hosts.
2. Full Coder template lifecycle: workspace recreate/restart, Docker persistence,
   private app route, websocket/large response behavior, parallel project ports.
3. Untouched Drupal CMS: restore sitemap/XMLWriter, Klaro/XPath, aggregate assets
   through stream wrappers, and cron; independently prove each before removing an
   exclusion. Migration/OAuth/MCP are outside scope, not future promises.
4. Published multi-architecture runtime images by immutable digest, provenance,
   cold-cache pulls and verified seed artifacts with no real users or credentials.
5. Alternative database backends only if they reduce blockers. MariaDB is the current
   working fixture path; SQLite is an earlier investigation, not the selected stack.
6. Matched HTTP-server and concurrency studies, memory/CPU profiles and long-running
   request isolation once correctness and a release build are established.
7. Broader PHP corpus gates and upstream maintainer review for each contribution.
8. Choose a license for original repository glue/documentation before inviting broad
   redistribution. PHP Rust-derived code retains its upstream license and notices.
